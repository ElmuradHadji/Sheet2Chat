# Sheet2Chat 📊 ➡️ 💬 ⚡

> **Excel cədvəllərinizi saniyələr içində hazır WhatsApp kontaktlarına və qruplarına çevirin.** 🚀  
> *Turn any spreadsheet into organized WhatsApp contacts in seconds.* ✨

---

## 🇦🇿 Azərbaycan dili

### 📌 Layihə Haqqında
**Sheet2Chat** — 🎓 təhsil mərkəzləri, 👨‍🏫 repetitorlar, 👥 icma menecerləri və 🎉 tədbir təşkilatçıları üçün hazırlanmış sürətli vCard (`.vcf`) generatorudur. Excel siyahılarını dərhal vizual kartlara çevirir, istədiyiniz şəxsləri seçməyə imkan verir və birbaşa telefona ötürülə bilən vahid kontakt faylı yaradır. 📲

### ✨ Əsas İmkanlar
* 🖱️ **Drag & Drop Yükləmə:** `.xlsx` fayllarını birbaşa interfeysə sürükləyərək sürətli emal etmə.
* 📇 **İnteraktiv Seçim Kartları:** Kontaktları yükləməzdən əvvəl ad, soyad və nömrələri vizual kart formasında nəzərdən keçirmə.
* ✅ **Toplu və Fərdi Seçim:** Hər kart üçün ayrıca checkbox və bir toxunuşla "Bütün hamısını seç" düyməsi.
* 📞 **Avtomatik Formatlama:** Yerli nömrələrin (məs: `050...`) standart beynəlxalq formata (`+994...`) avtomatik gətirilməsi.
* 🏷️ **Ağıllı WhatsApp Teqləri:** WhatsApp-da asan axtarış və qrup yığımı üçün adların sonuna etiket artırılması (məs: `Ad Soyad Ww EVS`).
* 🌐 **Tam UTF-8 Dəstəyi:** Azərbaycan və digər əlifbaların simvollarının (`ə`, `ı`, `ö`, `ğ`, `ç`, `ş` və s.) qüsursuz qorunması.

### 📑 Cədvəl Strukturu
Excel faylının 1-ci vərəqi aşağıdakı ardıcıllıqda olmalıdır:
* 🅰️ **Sütun A:** Ad
* 🅱️ **Sütun B:** Soyad
* 📞 **Sütun C:** WhatsApp Nömrəsi

### 🚀 İstifadə Qaydası
1. 📂 `.xlsx` faylını sistemə yükləyin.
2. 👁️ Ekranda açılan kartlardan qrupa əlavə etmək istədiyiniz şəxsləri işarələyin.
3. 📥 **".vcf Faylını Yüklə"** düyməsini sıxın və faylı telefonunuzda açaraq bütün kontaktları bir kliklə yaddaşa vurun.

## 🇬🇧 English

### 📌 About The Project
**Sheet2Chat** is an efficient, browser-based vCard (`.vcf`) generator designed for 🎓 educators, 🎟️ event coordinators, 💼 HR teams, and 👥 community admins. It parses spreadsheet data, presents contacts as interactive cards for validation, and exports them into a bulk `.vcf` phonebook file. 📲

### ✨ Key Features
* 🖱️ **Drag & Drop Upload:** Fast and intuitive file upload for standard `.xlsx` spreadsheets.
* 📇 **Visual Card Previews:** Review initials, full names, and sanitized phone numbers before generating output.
* ✅ **Granular Selection:** Toggle individual contact cards or use the master "Select All" switch.
* 📞 **Automated Sanitization:** Converts localized numbers (e.g., `050...`) into standard international format (`+994...`).
* 🏷️ **Smart Tagging:** Automatically appends identifier tags (e.g., `Firstname Lastname Ww EVS`) for instant WhatsApp group filtering.
* 🌐 **Full UTF-8 Encoding:** Native support for international character sets and localized letters.

### 📑 Spreadsheet Schema
The primary worksheet in your `.xlsx` workbook must follow this column layout:
* 🅰️ **Column A:** First Name
* 🅱️ **Column B:** Last Name
* 📞 **Column C:** WhatsApp Phone Number

### 🚀 How It Works
1. 📂 Upload your `.xlsx` contact list.
2. 👁️ Review the generated cards and select the contacts you wish to include.
3. 📥 Click **"Export (.vcf)"** and open the downloaded file on your mobile device to import all contacts in one tap.
